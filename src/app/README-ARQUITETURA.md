# Arquitetura por camadas

- `components/`: componentes de layout e composição visual.
- `pages/`: telas e fluxo de cada rota.
- `services/`: regras de acesso à API e estado compartilhado.
- `models/`: contratos e tipos usados pela aplicação.
- `pipes/`: pipes reutilizáveis.
- `guards/`: proteção de rotas.
- `interceptors/`: comportamento transversal das requisições HTTP.
- `shared/`: componentes visuais reutilizáveis.
- `util/`: funções auxiliares puras.
